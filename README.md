# Dimnote

Add real-world dimensions to your Figma designs in one click.

Dimnote is a Figma generative plugin, built with Figma Agent. Get it on [Figma Community](https://www.figma.com/community/generative-plugin/1687868792745109884/dimnote).

## Features

- Annotate one layer or many at once
- Auto placement, or Top / Bottom / Left / Right
- Gap dimensions between selected layers
- Every side of irregular straight-edged shapes, plus rotated layers
- Radius callouts for circles and arcs
- Units (mm, cm, m, in, ft), scale and decimal precision
- Endpoints as Slash, Arrow or Triangle; line weight, colours, font and size
- Live real-world size badge on the selected layer
